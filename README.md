# EG Booking V2

Application multi-utilisateurs prévue pour Supabase.

Fonctions : connexion, rôles admin/DJ/établissement, planning, bookings sans DJ, candidatures DJ, demandes d'établissement, profils et messagerie.

1. Crée un projet Supabase.
2. Exécute `supabase.sql` dans SQL Editor.
3. Copie `config.example.js` en `config.js` et renseigne l'URL + clé anon.
4. Héberge les fichiers sur GitHub Pages.
5. Crée le premier compte dans Authentication puis passe son rôle à `admin` avec la requête indiquée dans SQL.
